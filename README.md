# PadelTime

A modern web application for managing padel court bookings and reservations. Built as a Software Engineering course project by Team TG12.2. The app features a calendar-based booking system, secure authentication with Clerk, Stripe payment integration, and Google Maps for court locations.
- Wiki (in Croatian): https://github.com/dkranjcec/PROINZ-projekt/wiki
  
## Tech Stack

Next.js 16 • TypeScript • Tailwind CSS • React Hook Form • FullCalendar • Stripe • Clerk • AWS S3 • PostgreSQL • Google Maps API
